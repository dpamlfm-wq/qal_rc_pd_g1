Що я вивчила
Навчилася працювати з SQLAlchemy ORM.
Створювала моделі для таблиць PostgreSQL.
Використовувала CRUD-операції через ORM.
Підключала Python до PostgreSQL через SQLAlchemy.
Найскладніший момент
Найбільше часу зайняло налаштування моделей відповідно до реальної структури бази даних та виправлення помилок під час тестування.

Еврика-момент
Було цікаво побачити, що можна працювати з таблицями як з Python-об'єктами без написання SQL-запитів.

Порівняння SQL та ORM
ORM для мене виглядає простішим для щоденної роботи. Код читається легше і займає менше рядків.

План на Django
Думаю, що Django ORM буде легше вивчати після SQLAlchemy, тому що основні принципи вже знайомі.
